# Introduction
Hunger Pizzas is a pizza sales business that offers a variety of pizzas across different categories, sizes, and price ranges. The company maintains detailed records of its orders, pizza products, pizza categories, prices, quantities, and order timings.
This project focuses on analyzing the sales data of Hunger Pizzas to understand its overall business performance and identify important sales patterns. By combining information from the four available datasets, the analysis provides insights into customer ordering behavior, popular pizza products, category-wise performance, sales by size, and revenue contribution.
The project uses data analysis techniques to transform the raw sales data into meaningful business insights that can help Hunger Pizzas make better decisions regarding product offerings, pricing, inventory planning, and sales strategies.
# Objective
The primary objective of this project is to perform a Sales Analysis of Hunger Pizzas and evaluate the company's sales performance using historical order data.
The key objectives are:
•	Analyze the overall sales and revenue generated by Hunger Pizzas.
•	Identify the best-selling pizza products based on quantity sold.
•	Identify pizzas generating the highest revenue.
•	Analyze sales performance across different pizza categories.
•	Compare sales based on different pizza sizes.
•	Determine the most frequently ordered pizzas.
•	Analyze daily and monthly sales trends.
•	Identify peak ordering periods based on order time.
•	Understand customer ordering patterns through order quantities.
•	Determine which pizza categories and products contribute most to total revenue.
•	Provide actionable insights that can help improve sales, inventory planning, and business decisions.
# Dataset Description
The Hunger Pizzas dataset consists of four interconnected tables containing information about orders, pizza products, pizza types, and individual order details. These tables can be joined using common identifiers to perform comprehensive sales analysis.
 
### 1. Orders Table
The Orders table contains information about when each customer order was placed.
Column	Description
order_id	Unique identification number of each order
date	Date on which the order was placed
time	Time at which the order was placed
The table contains 21,350 orders, which can be used to analyze daily, monthly, and time-based ordering trends.
### 2. Pizza Types Table
The Pizza Types table contains information about the different types of pizzas offered by Hunger Pizzas.
Column	Description
pizza_type_id	Unique identifier for each pizza type
name	Name of the pizza
category	Category of the pizza, such as Chicken, Classic, Supreme, etc.
ingredients	Ingredients used to prepare the pizza
There are 32 different pizza types in the dataset.
### 3. Pizzas Table
The Pizzas table provides product-level information including pizza size and price.
Column	Description
pizza_id	Unique identifier for a specific pizza-size combination
pizza_type_id	Identifier connecting the pizza to its pizza type
size	Size of the pizza, such as S, M, L, XL, or XXL
price	Selling price of the pizza
The table contains 96 pizza variations, representing different pizza types and sizes.
 
### 4. Order Details Table
The Order Details table contains the individual items included in each order.
Column	Description
order_details_id	Unique identifier for each order-detail record
order_id	Identifier connecting the item to an order
pizza_id	Identifier of the pizza purchased
quantity	Number of units of the pizza ordered
The table contains 48,620 order-detail records and is the primary table used for calculating quantities sold and revenue.
Relationship Between Tables
The tables are connected using common keys:
Orders → Order Details → Pizzas → Pizza Types
•	orders.order_id 		→ 	order_details.order_id
•	order_details.pizza_id 		→ 	pizzas.pizza_id
•	pizzas.pizza_type_id 		→ 	pizza_types.pizza_type_id
This relationship allows the analysis to combine order timing, pizza information, category, size, price, and quantity into a single analytical dataset.
For example:
Revenue = Pizza Price × Quantity Ordered
This calculated measure can then be used to analyze total revenue, product performance, category performance, and sales trends.
